# CCAR-F 学習ノート

Claude Certified Architect – Foundations (CCAR-F) の出題ブループリントを目次にした学習用サイト。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（ドメイン一覧） |
| `00-basics.html` | 前提 — 会話の実体 |
| `01-agentic.html` | Domain 1 — エージェント設計とオーケストレーション (27%) |
| `02-tools.html` | Domain 2 — ツール設計と MCP 連携 (18%) |
| `03-claude-code.html` | Domain 3 — Claude Code の設定とワークフロー (20%) |
| `04-prompt.html` | Domain 4 — プロンプト設計と構造化出力 (20%) |
| `05-context.html` | Domain 5 — コンテキスト管理と信頼性 (15%) |
| `06-summary.html` | まとめ・総合チェック |
| `assets/` | スタイル・スクリプト・検索インデックス・設問データ |

## 使い方

`index.html` をブラウザで開くだけです。ビルドもサーバも不要。

- `/` キーまたは右下のボタンで全文検索
- 右下のアイコンでライト / ダーク切替
- 各ドメインの末尾に理解度チェック
