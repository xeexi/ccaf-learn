2-8　組み込みのツールを選ぶ

Claude Code には最初からツールが入っています。同じことが複数の道具でできてしまうので、選び方の基準が要ります。

BLUEPRINT 2.5組み込みツールの選択と活用

ゴール組み込みツールの系統と、選び分けの基準を言える。

図の読み方

  1. 1上の5系統はできることの範囲が順に広がります。右にいくほど、渡したときに起きうる範囲が大きくなります。
  2. 2変えるの2つは使い分けがあります。既存の一部を直すのが Edit、丸ごと置き換えるのが Write。全体を書き直すと、意図しない箇所まで消えます。
  3. 3下の2枠が判断の分かれ目です。同じ「探す」でも、専用のツールと Bash 経由では確認が出るかどうかが変わります。設問では権限とセットで問われます。
  4. 4いちばん下の一文が実務で効きます。ツール名を3か所で同じ文字列として使うので、名前を覚えることがそのまま権限設計とフック設定につながります。
名前が効く3か所 ・権限の設定（許可／拒否の対象）
・子に渡すツールの一覧
・フックをどのツールで発火させるかの一致条件
誤解「Bash があれば、読む・探すも全部それで済む」 実際はできることは同じでも権限の扱いが違います。専用のツールなら作業ディレクトリの中で確認なしに動きますが、Bash は既定で確認が出ます。「なぜ調査が毎回止まるのか」の答えがここにあることが多い。

ポイントできることが同じでも権限の面が違う。ツール名は権限・子への配布・フックで共通の識別子。
