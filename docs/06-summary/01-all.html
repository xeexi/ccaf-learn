6-1　1枚で全体を見る

最初の図に、学んだ要素を書き込むとこうなります。

ゴール初見の設問が「どこの話か」を特定できる。

ポイント個々の用語ではなく、この1枚の関係が頭に入っていれば、初見の設問でも「どこの話か」を特定できる。

この1枚を、言葉で辿ってみる

①〈プロンプト〉　ずっと効かせたいことを system に、その回の入力を user に置きます。長い資料は前、指示は後ろ（Domain 4）。この並びは同時にキャッシュも効かせます（前提編）。

②〈Claude〉　渡されたものを毎回まるごと読み、次の1トークンを確率で選び続けます（前提編）。答え終わると stop_reason を付けて返します（Domain 1）。

③〈ツール / MCP〉　tool_use が返ってきたら、アプリがここを実行します（Domain 2）。読むだけの操作はそのまま、変える操作は関門を通して。1体で足りなければ、ここを子に切り出します（Domain 1）。

④〈アプリが返す〉　結果を tool_result として会話の末尾に足し、①へ戻ります ─ これがループです（Domain 1）。

外から効く2つ　コンテキストウィンドウには①〜④の全部が乗るので、溢れそうなら要約するか、子に逃がす（Domain 5）。必ず走らせたい処理だけは、モデルを通さずフックへ（Domain 1・Domain 3）。

迷ったときに戻る一文 判断が要ることはモデルへ、要らないことはコードへ。そして、効く一番単純な手を選ぶ。
CCAR-F の設問で選択肢に迷ったら、この基準で切ると、たいてい残るものが正解です。
