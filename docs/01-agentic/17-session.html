BLUEPRINT 1.7セッション状態・再開・分岐の管理

ゴール再開・枝分かれ・新規の使い分けができる。

再開枝分かれ新規
コマンド claude --continue（直前）
claude --resume（一覧から選ぶ）		 claude --resume <id> --fork-session claude
もとの会話 そのまま伸びる 変わらない。別 ID で枝ができる 関係しない
選ぶ場面 続きをやる 同じ地点から複数の案を試して比べる 前の文脈が邪魔なとき
窓の重さ 軽くならない。長くなった会話は長いまま戻る 軽くならない。枝を切った地点の重さを引き継ぐ 軽い。ただし前提の渡し直しが要る

ポイント再開は文脈を保つ手、枝は同じ地点から分ける手、新規は文脈を捨てる手。窓を軽くするのはどれでもない。

新規を選ぶと渡し直しの手間が増えるので、CLAUDE.md に書けることは先に書いておくと楽になります。

誤解「セッションを再開すれば、軽い状態から始まる」 実際は履歴ごと復元されるので、再開した時点の重さがそのまま戻ります。軽くしたいなら圧縮するか、新規で始めて必要な前提だけ渡します。
