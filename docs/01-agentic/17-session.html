BLUEPRINT 1.7セッション状態・再開・分岐の管理

ゴール再開・枝分かれ・新規の使い分けができる。

図の読み方

  1. 1上の帯を伸ばすのが再開です。直前のものを開くか、ID や名前で選ぶかの違いしかありません ── --continue と --resume。
  2. 2橙の枝が --fork-session です。もとのセッションは変わらないので、同じ地点から複数の案を試して比べられます。
  3. 3伸ばすのだから窓は空きません。長くなった会話は長いまま戻ります。ここを取り違えると「再開したのに重い」と悩みます。
  4. 4新規を選ぶのは前の文脈が邪魔なときです。渡し直しの手間が増えるので、CLAUDE.md に書けることは先に書いておくと楽になります。
コマンドの形 claude --continue … 直前の会話を開く
claude --resume … 一覧から選ぶ（ID や名前を渡せる）
claude --resume <id> --fork-session … その地点から別 ID で枝を作る
誤解「セッションを再開すれば、軽い状態から始まる」 実際は履歴ごと復元されるので、再開した時点の重さがそのまま戻ります。軽くしたいなら圧縮するか、新規で始めて必要な前提だけ渡します。

ポイント再開は文脈を保つ手、枝は同じ地点から分ける手、新規は文脈を捨てる手。窓を軽くするのはどれでもない。
