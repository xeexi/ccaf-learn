1-17　ツール呼び出しに割り込む

ゴール割り込みでできる4つを言い分けられる。

道具が動く直前と直後に、こちらの処理を挟めます（フック）。〈前提は関門で、引き継ぎは欄で〉の関門は、このうち「止める」だけを使った形です。

BLUEPRINT 1.5Apply Agent SDK hooks for tool call interception and data normalization

ポイント割り込める場所は前と後の2つ。できることは止める・入力を書き換える・出力を差し替える・記録するの4つ。

誰が、何をしているのか

ゴール割り込みを呼ぶのも判定を適用するのもアプリ側だと言える。

フックは「Claude が動かすもの」ではありません。呼ぶのも、返ってきた判定を適用するのも Claude Code（アプリ）です。モデルは最初に「使いたい」と言っただけで、以降には関われません。

※ 「必ず起きてほしい処理を仕組み側に置く」という考え方そのものは Domain 5 の〈確実にしたいことは仕組み側へ〉にあります。ここはその割り込み口の中身です。
※ どこに書いて、どのツールに効かせるかは次の〈どこに書いて、どう止めるか〉、入力の書き換えと形そろえの実物はその次の〈割り込みで形をそろえる〉で扱います。
