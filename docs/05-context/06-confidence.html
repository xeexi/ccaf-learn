5-6　確信が持てないときに止める

確率で答えを作る仕組みは、根拠が薄いときも同じ調子で答えます。止まる道を用意していないと、迷いは黙って誤答になります。

BLUEPRINT 5.2エスカレーションと曖昧さの解消　／　BLUEPRINT 5.5人のレビュー導線と確信度の校正

ゴール止まる道を用意する設計と、その置き場所を言える。

図の読み方

  1. 1上（赤）が逃げ道がない形です。答えの形を1種類に絞ると親切なようで、実は迷いを隠すことになります。
  2. 2もっともらしい誤答が最悪なのは、後から見分けられないことです。自信のない答えと自信のある答えが同じ見た目で出てきます。
  3. 3下（緑）の3行目が要点です。止める判定はコード側に置きます ── 「自信がないときは止まって」と頼む形にすると、止まるかどうかがまた確率になります。
  4. 4人に渡すを出口として設計しておくと、止まった件数がそのまま数字になります。全部を自動で通そうとするより、運用が長持ちします。
誤解「自信の度合いを数値で答えさせれば、それで判定できる」 実際はその数値も同じ仕組みで生成された確率的な出力です。参考にはなりますが、判定の根拠を数値だけに置くと、外側で検算しているつもりで何もしていないことになります。

ポイント迷いを表現できる受け皿と、止める判定を外に置く。止まった件数は運用の指標になる。
