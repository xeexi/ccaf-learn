図の読み方

  1. 1残すものの1行目は引数まで含めます。「検索した」だけでは再現できず、同じ条件で試せません。
  2. 22行目の出典（provenance）が抜けると、結論が正しいかを人が確かめられません。あとで裏取りするための唯一の手がかりです。
  3. 3赤の側で残っているのは結論だけです。もっともらしく見えるので、間違いに気づく契機そのものがなくなります。
  4. 4下の注記のとおり、記録は判断が要らない処理です。だから前節の線引きに従って、モデルに頼まず仕組み側に置けます。
やり直しを安全にする 同じ操作を2回走らせても結果が変わらない形（同じ ID で登録し直すと上書きになる、など）にしておくと、途中で失敗しても記録を見て途中から再実行できます。
