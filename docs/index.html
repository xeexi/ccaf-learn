CLAUDE CERTIFIED ARCHITECT ─ FOUNDATIONS

CCAR-F 学習ノート

この試験が問うのは Claude Code・Claude Agent SDK・Claude API・MCP の4つを使った設計判断です。公式は「6か月以上、実際に作った経験のある人」を想定しています。

本試験は 60問・120分、合格は 1,000点満点中 720点。出る範囲は公式 Exam Guide のブループリントで決まっていて、この教材はそれをそのまま目次にしています。
設問は6つのシナリオのうち4つから出ます。1つ選ぶものと、複数選ぶものが混じり、何個選ぶかは設問に書かれています。
採点は他の受験者との比較ではなく、決められた水準に達したかで決まります。結果にはドメインごとの正答率も出ますが、合否は総合点だけで決まります。

何が、何問出るか

読む順番

用語がどの項で初めて出るかを全項で数えたところ、順番が決まっているのは4つだけでした。残る Domain 3 と Domain 5 は、Domain 1 さえ読んでいれば、どちらから読んでも構いません。

2種類の番号

公式と、この教材とで数える単位が違います。番号を見間違えないよう、ここだけ先に。

公式 Exam Guideこの教材
単位 タスク（Task Statement）　30個。出題の単位で、1つから複数問出る 項　95個。読む単位で、1項が1画面ぶん
番号の形 1.1 5.6 ── ドット 1-3 5-10 ── ハイフン

1つのタスクを複数の項に割ることがあります（例：1.1 は 1-3〜1-7 の5項）。各項の冒頭に TASK STATEMENT 1.1 と出ていれば対応するタスク、出ていなければ土台・導入・まとめ・模擬試験です。

全項目一覧

全 95 項。◇ が理解度チェックで、そこが区切りです。1項＝1画面なので、区切りまでの項数がそのまま「一度に読む量」になります。
