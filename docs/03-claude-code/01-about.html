3-1　このドメインについて

Claude Code を「使えるようにする」のではなく、チームの決まりごとを設定として置くのがこのドメインです。人が毎回言わなくても守られる状態をどう作るか、という話に終始します。

  • 繰り返す作業の置き場所
  • CI で先に決めておくこと
