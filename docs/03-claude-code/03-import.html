3-3　@import で分割する

CLAUDE.md が長くなったら、テーマごとに分けて読み込みます。

BLUEPRINT 3.1CLAUDE.md の階層・スコープ・モジュール化

ゴール@import で減るものと、減らないものを言える。

図の読み方

  1. 1左が本体。行頭に @パス と書くだけで、その中身がそこに展開されます。
  2. 2相対パス・絶対パス・~/ の3通りが使えます。相対パスは、その行を書いたファイルから見た位置です。
  3. 3入れ子は4段まで。import した先がさらに import しても、4ホップで止まります。
  4. 4コードスパン（バッククォート）やコードブロックの中の @ は展開されません。
設問での問われ方 「CLAUDE.md が肥大化して読みにくい。どう整理するか」→ テーマごとにファイルを分け、@import で束ねる。
「個人の好みをチームに押し付けずに読み込みたい」→ @~/.claude/my-rules.md のようにホーム側を import する、または CLAUDE.local.md を使う。

ポイント@import は「分割して見通しを良くする」ための道具。展開後は結局1つにつながるので、合計の量は減らない。
