3-7　パス固有ルール

.claude/rules/ に置き、frontmatter で対象パスを指定します。

BLUEPRINT 3.3条件付き規約読み込みのためのパス固有ルール

ゴールpaths が何のスイッチか説明できる。

図の読み方

  1. 1左上がルールファイルの中身。frontmatter の paths: にグロブを並べるだけです。
  2. 2「いつ読まれるか」 ── ここが CLAUDE.md との違いです。paths を書けばそのファイルを扱うときだけ、書かなければ常に窓に載ります。関係ない規約でウィンドウを埋めないための仕掛けです。
  3. 3「こう書ける」 ── 複数パターンと {ts,tsx} のブレース展開。1ファイルで複数の拡張子をまとめられます。
  4. 4「サブディレクトリも掘れる」 ── 分けて置いても自動で拾われるので、規約の種類が増えても1ファイルが肥大しません。
CLAUDE.md との使い分け 常に効かせたい規約（言語共通の方針）→ CLAUDE.md
特定の種類のファイルにだけ効かせたい規約（Reactコンポーネントの書き方、テストの命名）→ .claude/rules/ ＋ paths
後者を CLAUDE.md に全部書くと、関係ない作業のときも窓を食い続けます。

ポイントpaths は「いつ読ませるか」のスイッチ。規約が増えたときに、窓を守りながら増やせる仕組み。
